# Índice central da documentação

Esta pasta concentra a documentação principal da plataforma. A forma correta de usar este índice é escolher a trilha pelo tipo de dúvida real, e não pelo nome do arquivo.

Em linguagem simples: se o [README da raiz](../README.md) apresenta o produto como plataforma de IA e organiza a visão global do repositório, este arquivo organiza a navegação interna da pasta docs para quem precisa estudar, implantar, operar, vender, integrar ou evoluir a solução.

## Como usar este índice

Use este arquivo quando a pergunta for uma destas:

- como a plataforma se posiciona para negócio e portfólio;
- como a arquitetura funciona na prática;
- onde estão os documentos de ingestão, ETL, RAG e NL2SQL;
- como funcionam DeepAgents, workflows, YAML, AST e runtime agentic;
- onde ficam AG-UI, HIL, canais e integrações;
- quais documentos ajudam em onboarding, governança e metodologia.
